配置同步凭据

首次使用需粘贴一个 GitHub Token（仅保存在本机浏览器 localStorage， 不上传、不进仓库）。
创建路径：GitHub → Settings → Developer settings → Fine-grained tokens → 新建，仅授权 Anthony-hcy/Favorites 仓库的 Actions: Read and write 权限。
